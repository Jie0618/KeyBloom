# KeyBloom

KeyBloom 是一个 macOS 菜单栏小工具，用来统计每天的键盘活动。

## 功能

- 今日按键总数、逐小时分布
- 按天或按周查看历史数据，可用左右箭头或日历选择日期
- 近 7 天逐日趋势
- 每个键独立计数，并以虚拟 ANSI 键盘热力图展示；点击键帽可查看准确次数
- 左右 Shift、Control、Option、Command 和 Fn 独立统计；通过 HID 事件识别常见 Mac 顶排功能键，不要求先把它们切换成标准 F 键
- 字母、数字、标点与控制键、修饰键、导航键的分类统计
- 一键暂停和恢复
- 登录 macOS 时自动启动并开始统计
- 数据只保存在本机

程序监听系统发出的按键事件，但不会读取或保存字符、剪贴板、输入顺序或文本。磁盘上只保存按日期、小时和 macOS 虚拟键码汇总的计数。统计会包含系统自动重复产生的按键事件。

## 系统要求

- macOS 13 或更新版本
- Apple Command Line Tools（脚本可在缺少时提示安装）
- 当前用户的登录钥匙串可用

## 构建和运行（不需要完整 Xcode）

1. 解压项目。
2. 双击 `运行KeyBloom.command`。首次运行时，如果系统提示安装 Apple 命令行工具，请完成安装后再次双击脚本；不需要安装完整 Xcode。
3. 脚本会编译并安装到 `~/Applications/KeyBloom.app`，首次运行时会在当前用户的钥匙串创建本机签名身份，然后打开菜单栏 App。若系统没有返回登录钥匙串路径，脚本会尝试使用 macOS 的默认钥匙串。若 macOS 阻止脚本或 App 首次打开，在 Finder 中按住 Control 点它并选择“打开”。
4. 在菜单栏点键盘图标，选择“申请授权”。按钮会请求输入监控授权并打开系统设置。
5. 在“系统设置 > 隐私与安全性 > 输入监控”中启用 `~/Applications/KeyBloom.app`，不要授权 Terminal，也不要只启用旧版 KeyTrack。若系统要求确认后台启动，再到“系统设置 > 通用 > 登录项”允许 KeyBloom。
6. 回到 KeyBloom 后，应用会重新检测授权并重建监听；也可以点“刷新并开始”或“重新连接”。状态显示监听中后，在其他 App 输入几次，面板会显示最近收到按键的时间。若仍没有按键记录，请完全退出并重开 KeyBloom，确认授权列表勾选的是 KeyBloom。

全局键盘事件监听和登录启动都由 macOS 的系统设置管理。你可以随时撤销权限、关闭开机启动，或从 KeyBloom 面板暂停统计。关闭统计面板不会退出程序，仍会继续记录；完全退出程序后停止监听，下一次启动时恢复。应用从系统设置回到前台时会再次检测授权。App 未运行或尚未获得授权的历史按键无法事后恢复。首次启动新版 KeyBloom 时，如果新目录还没有统计文件，会从旧版 KeyTrack 文件导入历史记录；原文件保留不删除。迁移前请先退出旧版 KeyTrack，并关闭旧版的登录启动，避免同时统计。

## 签名身份与权限

每次重新编译都会改变临时签名的代码哈希，macOS 可能因此把 App 识别成新程序。构建脚本现在会在本机钥匙串创建并重复使用 `KeyBloom Local Signing` 自签名证书；私钥只保存在你的 Mac 上，不会放进下载包。首次从旧版迁移时，脚本只重置 KeyBloom 自己的输入监控授权，需要重新允许一次。之后只要保留钥匙串中的该签名身份，更新通常不再需要重复授权。如果删除了该身份，新的签名也会被 macOS 视为新程序。

该自签名仅用于这台 Mac 上保持稳定身份，不是 Apple Developer ID 证书，也不会对 App 做公证；首次打开时 macOS 仍可能要求手动确认。

## 数据位置

新版统计文件位于：

```text
~/Library/Application Support/KeyBloom/keyboard-stats.json
```

首次启动时，若该文件不存在，KeyBloom 会从 `~/Library/Application Support/KeyTrack/keyboard-stats.json` 导入旧版历史数据；旧文件会保留。

文件只含每天的计数、各小时计数和各虚拟键码计数。应用每 5 秒写入一次，暂停或退出时会立即保存。热力图以 ANSI 键盘位置显示按键码；不同键盘布局的键帽标注可能不完全对应。macOS 会把修饰键和部分顶排功能键作为不同事件上报，KeyBloom 会按左右侧分别追踪修饰键，并从 HID 事件和系统按键事件中识别常见 Apple 顶排上的 Mission Control、Launchpad、亮度、媒体、快进和倒退键，映射到对应 F 键位置。对于其他键盘或厂商自定义的功能键，HID 可能只提供功能名称而不提供其物理位置，因此无法保证每种自定义键盘都能准确还原实体键位；这时可以按住 Fn/🌐 发送标准 F 键，或启用“将 F1、F2 等键用作标准功能键”。

## 当前限制

本项目提供源码和 macOS 命令行构建脚本。构建需要 Apple 命令行工具，但不需要完整 Xcode。KeyBloom 使用新的 Bundle ID，需要在“输入监控”中单独授权。
