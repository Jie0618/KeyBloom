# KeyBloom

KeyBloom 是一个 macOS 菜单栏小工具，用来统计每天的键盘活动。

## 功能

- 今日按键总数、逐小时分布
- 近 7 天趋势和平均值
- 每个键独立计数，并以虚拟 ANSI 键盘热力图展示；点击键帽可查看准确次数
- 字母、数字、标点与控制键、修饰键、导航键的分类统计
- 一键暂停和恢复
- 登录 macOS 时自动启动并开始统计
- 数据只保存在本机

程序监听系统发出的按键事件，但不会读取或保存字符、剪贴板、输入顺序或文本。磁盘上只保存按日期、小时和 macOS 虚拟键码汇总的计数。统计会包含系统自动重复产生的按键事件。

## 系统要求

- macOS 13 或更新版本
- Apple Command Line Tools（脚本可在缺少时提示安装）

## 构建和运行（不需要完整 Xcode）

1. 解压项目。
2. 双击 `运行KeyBloom.command`。首次运行时，如果系统提示安装 Apple 命令行工具，请完成安装后再次双击脚本；不需要安装完整 Xcode。
3. 脚本会编译并安装到 `~/Applications/KeyBloom.app`，然后打开菜单栏 App。若 macOS 阻止脚本或 App 首次打开，在 Finder 中按住 Control 点它并选择“打开”。
4. 在菜单栏点键盘图标，选择“申请授权”。按钮会请求输入监控授权并打开系统设置。
5. 在“系统设置 > 隐私与安全性 > 输入监控”中启用新的 `~/Applications/KeyBloom.app`，不要授权 Terminal，也不要只启用旧版 KeyTrack。若系统要求确认后台启动，再到“系统设置 > 通用 > 登录项”允许 KeyBloom。
6. 回到 KeyBloom 后，应用会重新检测授权并重建监听；也可以点“刷新并开始”或“重新连接”。状态显示监听中后，在其他 App 输入几次，面板会显示最近收到按键的时间。若仍没有按键记录，请完全退出并重开 KeyBloom，确认授权列表勾选的是 KeyBloom。

全局键盘事件监听和登录启动都由 macOS 的系统设置管理。你可以随时撤销权限、关闭开机启动，或从 KeyBloom 面板暂停统计。关闭统计面板不会退出程序，仍会继续记录；完全退出程序后停止监听，下一次启动时恢复。应用从系统设置回到前台时会再次检测授权。App 未运行或尚未获得授权的历史按键无法事后恢复。新应用使用原来的 KeyTrack 统计文件以保留历史记录；首次启动 KeyBloom 前请先退出 KeyTrack，并关闭旧版的登录启动，避免两个应用同时写入数据。

## 数据位置

统计文件位于：

```text
~/Library/Application Support/KeyTrack/keyboard-stats.json
```

文件只含每天的计数、各小时计数和各虚拟键码计数。应用每 5 秒写入一次，暂停或退出时会立即保存。热力图以 ANSI 键盘位置显示按键码；不同键盘布局的键帽标注可能不完全对应。

## 当前限制

本项目提供源码和 macOS 命令行构建脚本。构建需要 Apple 命令行工具，但不需要完整 Xcode。KeyBloom 使用新的 Bundle ID，需要在“输入监控”中单独授权。
